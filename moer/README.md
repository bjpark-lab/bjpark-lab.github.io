# MOER 농구팀 전술 라이브러리

공개 주소: https://bjpark-lab.github.io/moer/

모어 농구팀의 「모어 농구 용어 정리」 구글 슬라이드 33장을 출처로 정리한 별도 전술노트입니다.
원본: https://docs.google.com/presentation/d/1rdQghY_RAlO8hHioJV0gkotcctBrjcF-uSgwOM-Pn2k/edit

## 구성
- 기초 움직임: 핀다운, 립, 플레어, 피스톨, 해머, 스페인 픽앤롤, 더블 드래그(77), 트위스트, 스태거, 줌, 아이버슨 3개 옵션, 플렉스
- 사이드 패턴: SA, BD
- 엔드 패턴: TR, ZL, SH
- 팀 공격: 더블 스태거, 셔플 스태거, 댄 헐리 2

## 사용
전술 선택 → 단계 버튼 또는 자동 재생 → 좌우 반전, SVG 저장, 링크 복사.
즐겨찾기는 브라우저에 저장됩니다. 선택한 전술은 URL 쿼리로 공유됩니다.

## 자료 충실도
전술판의 좌표와 동선은 슬라이드의 글 설명을 바탕으로 재구성한 개념도입니다.
영상·그림에만 상세 동선이 있는 BD, TR, ZL, SH는 확인되지 않은 움직임을 만들지 않고 원본 링크로 연결합니다.

## 유지보수
index.html: 화면 / style.css: 스타일 / plays.js: 전술 데이터 / app.js: 코트와 컨트롤.
plays.js의 각 단계 pos는 1~5번 선수 좌표, ball은 볼 소유 선수 번호입니다.
SSIT 사이트는 ../basketball/에 독립적으로 남아 있습니다.
