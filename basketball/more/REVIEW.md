# MORE 전술판 배치 검수 기록 (2026-11-24)

## 범위
모어 농구팀의 **모어 농구 용어 정리** 구글 슬라이드 33장 중, 현재 사이트에 구현된 전술·개념 22개를 점검함.

- 단계별 전술판 18개: 선수 위치, 간격, 3점 위치, 볼 소유, 스크린, 옵션 분기 검수 및 수정
- 원본 연결형 4개(BD, TR, ZL, SH): 이미지·동영상 내용을 확인하지 않은 상태에서 임의의 동선을 생성하지 않음

원본: https://docs.google.com/presentation/d/1rdQghY_RAlO8hHioJV0gkotcctBrjcF-uSgwOM-Pn2k/edit

## 좌표 기준
- 코트: 폭 500, 높이 510, 공격 골대 위쪽, 골대 중심 (250, 52.5)
- FIBA 3점 라인: 원호 반경 225, 코너 직선은 x≈30 / x≈470
- 선수 중심 간 거리가 34 미만인 경우 겹침 오류로 처리
- 파란 이동, 빨간 패스, 노란 슛, 보라 스크린 표시 유지

## 재발 방지
- `basketball/tests/validate-more-geometry.cjs`로 18개 전술의 좌표, 겹침, 코너 3점 기준, 옵션 분기를 빌드 때 검사
- `basketball/tests/browser-smoke.cjs`에서 공개 페이지의 22개 전술을 PC·모바일에서 열어 검사
- 18개 전술의 주요 단계 코트 스크린샷을 GitHub Actions 아티팩트에 보관

## 정확도와 한계
이 전술판은 **모어 문서에 기록된 전술 설명과 통용되는 농구 간격을 기준으로 재구성한 개념도**다. 
원본 동영상/GIF의 모든 프레임을 대조해 복원한 것은 아니며, 실제 팀이 약속한 선수 번호·공격 방향·컷의 세부 타이밍과 차이가 있을 수 있다.
특히 SA, 더블 스태거, 셔플 스태거, 댄 헐리 2는 연습 전 팀원들이 원본 슬라이드와 대조하는 것이 좋다.
