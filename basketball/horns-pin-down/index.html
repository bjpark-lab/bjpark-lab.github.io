혼즈 핀다운 엔트리

4번이 엘보에서 코너로 내려가 다운스크린 → 2번이 오른쪽 슬롯/탑으로 올라옴 → 1번이 2번에게 패스. 각 단계를 누르거나 자동 재생해 동선을 확인하세요.

STEP 01 / 04

혼즈 초기 배치

1번은 탑에서 공을 가지고, 4번·5번은 양쪽 엘보, 2번·3번은 양쪽 코너에 위치합니다.

PC에서는 ← → 키로 단계를 이동할 수 있습니다. 코트의 위치는 개념도이며 실제 스크린 각도는 수비 위치에 맞춰 조정합니다.

2번이 공을 받은 뒤

  • 캐치앤슛: 수비가 스크린에 걸렸다면 즉시 3점 시도
  • 컬 컷: 수비가 강하게 따라붙으면 스크린 안쪽으로 말려 들어가 골밑 공략
  • 슬립 / 실링: 수비가 스위치하면 4번이 미스매치를 활용
  • 2대2 연결: 2번이 공을 받은 뒤 4번과 픽앤롤·핸드오프로 전개

코칭 포인트: 4번은 스크린을 움직이지 않고 고정하고, 2번은 수비와 간격을 줄여 스크린을 바짝 타며, 1번은 패스 각도를 확보합니다.
