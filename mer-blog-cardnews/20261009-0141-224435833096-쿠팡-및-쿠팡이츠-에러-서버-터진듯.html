쿠팡 및 쿠팡이츠 에러, 서버 터진듯

요약

AI 생성 요약 · 원문 링크에서 전체 맥락 확인

쿠팡과 쿠팡이츠 서비스에서 동시에 장애가 발생하여 사용자들이 이용에 불편을 겪고 있습니다. 두 서비스가 같은 계정 인증 시스템을 공유하고 있다는 점으로 미루어 볼 때, 공통 인증 서버에 오류가 발생한 것으로 추정됩니다. 장바구니 데이터 등은 정상적으로 조회되는 것으로 보아 개인정보나 주문 데이터 자체가 손실된 상황은 아닌 것으로 보입니다. 이번 장애로 인해 심야 배송 분류 작업이 중단되어 새벽 배송에 차질이 생길 가능성이 있으며, 쿠팡이츠 배달원들에게는 배달 중인 음식을 자체 폐기하라는 지침이 전달되었습니다. 특히 연휴 시작과 맞물린 야식 배달 피크타임에 서비스가 멈춰 배달원과 자영업자들의 피해가 클 것으로 예상됩니다. 과거 사례를 비추어 볼 때 인증 서버 복구에는 일정 시간이 소요될 전망입니다. 전문가들은 반복적인 로그인 시도가 계정 잠금으로 이어질 수 있으므로, 시스템이 정상화될 때까지 무리한 접속을 자제하고 기다리는 것을 권장하고 있습니다.

쿠팡 서버가 터진 것 같음. 쿠팡만 터진게 아니라 쿠팡이츠도 같이 터짐. 쿠팡과 쿠팡이츠가 동시에 터졌다는 것은 공통 로그인(인증) 시스템 장애가 원인으로 생각됨. 쿠팡과 쿠팡이츠는 같은 쿠팡 계정으로 로그인을 함.

결제나 검색처럼 따로 도는 기능에 문제라면 쿠팡이나 쿠팡이츠 한쪽만 멈추는데, 이번에는 쿠팡과 쿠팡이츠 모두 장애가 나온 것임. 이미 로그인된 상태인데도, 로그인이 유효한지 서버에서 확인받지 못하면, 앱은 " 로그아웃됐다 "고 판단해서 로그인 화면을 띄우게 됨. 지금 상황이 그럼. 장바구니는 잡히는 것을 보면, 주문 데이터는 살아있는 것 같음.

주문이나 장바구니 같은 데이터 서버는 정상이고, 이 사람이 누구인지 확인하는 인증 단계만 문제가 생겨서 막힌 상태로 보임. 개인정보나 주문데이터가 날아간 상황은 아닌것 같다는 말임. 쿠팡을 아파트로 비유하면, 출입카드 인증서버에 문제가 생겨서 출입카드를 찍어도 현관문이 열리지 않는 상황과 비슷함. 쿠팡과 쿠팡이츠는 같은 단지의 다른 동인데, 출입카드 인증서버를 같이 쓰기 때문에 두 앱이 동시에 막힌 것 같음.

과거 사례를 보면, 인증서버 문제는 구글이 50분, MS가 5시간 정도에 복구를 했음. 자고 일어나면 복구가 되어있을 것 같음. 연휴 시작이라 야식배달 피크타임인데, 쿠팡 이츠로 야식 배달이 중단된 것은 타격이 꽤 클 것 같음. 배달하시는 분들이나 자영업자 분들도 배달중단등 곤란한 일들이 많이 생기고 있는 상황으로 보임.

시스템이 멈추다보니, 쿠팡 물류센터 심야배송 분류작업등도 모두 올스톱이라, 내일 새벽배송이 어려울 수 있음. 쿠파이츠의 배달원들에게는 지금 배달중인 음식들을 자체 폐기하라는 메시지가 갔다고 함. 이럴때 주의할 점은 로그인을 계속 시도하지 않는 것임. 로그인 실패가 계속 반복되면, 계정잠금을 당할 수 있음.
